# Crypto Moonboys SEO continuation — 14 November 2026

## Scope

Follow-up to [13 November sitemap/canonical audit](seo-audit-2026-11-13.md), focused on the **published GitHub Pages artifact**, its canonical signals, and semantic homepage heading structure. There are 459 URLs in the committed sitemap (418 wiki entries + 41 other entries at review time). A sample across the approved wiki showed that many pages have real content, titles, robots and OG metadata, **but lack a canonical head link**.

This update does **not** rewrite lore, public mission text, games, leaderboard scoring, Worker endpoints, Telegram sessions or WAX token and payout code. It does not submit to Search Console or assert index coverage.

## Confirmed evidence

- `wiki/altcoins.html`, `wiki/waxp.html`, `wiki/xrp-ledger.html`, several First Witness articles and other representative public wiki entries lack an explicit canonical link, while a number of GKniftyHEADS template pages already have self-canonicals. This is source-level canonical coverage drift, not evidence that these pages are absent from search engines.
- The indexable root/homepage currently had four visually prominent `h1` elements. The first remains the sole `h1`, and its three existing sibling slogans become `h2` with identical wording and shared visual CSS styles.
- The public site has separate historical, wiki, category and game routes; the sitemap source alone does not prove Googlebot rendering, HTTP redirection, current indexing or page speed.
- **Retrieval correction:** `wiki/hodlmoonboys-nft-collection.html` is NOT an empty file. GitHub lists its blob as 1,434,907 bytes. An earlier file-content read returned zero bytes through the connector because of the tool's content limit. Do not delete or exclude that page based on this artifact.

## Publication fix

New `scripts/seo-publish-canonicals.mjs` reads the copied `public-site/sitemap.xml` in the already-built Pages artifact. It checks each exact URL, reads its copied HTML, and adds `<link rel="canonical" href="...">` **only when missing**. The source wiki files stay byte-for-byte unchanged. The repair runs after copying assets and before the public-disclosure scan. No separate runtime JavaScript is needed, so crawlers see the preferred canonical in initial HTML.

Guardrails:
- A duplicate canonical, conflicting canonical, noindex document, meta-refresh redirect, invalid sitemap URL, missing HTML document or missing head is a **build error**. The existing Pages deploy will then not replace the previously published site. It preserves the current NBG Worker compatibility preflight unchanged.
- The script validates the entire sitemap **before writing** any HTML changes, and is idempotent. Warnings for editorial metadata gaps (e.g. missing descriptions and OG URL drift) are disclosed, not guessed or rewritten.
- Only the copy inside `public-site` is modified. It does not mass-edit protected W81 source HTML.
- The normal source audit `npm run seo:audit` remains read-only and may still show missing wiki canonicals. To check the **actual deployable artifact**, run it with `--root public-site`.

## Validation

Run locally (Node 22+), or on the feature branch in a manual GitHub Actions workflow:

```bash
npm ci
npm run seo:test
npm run seo:audit -- --json
node scripts/prepare-pages-artifact.mjs public-site
npm run seo:audit -- --root public-site --json
npm run seo:audit -- --root public-site --strict
npm run ci:wiki
```

The last strict command may reveal **pre-existing editorial warnings**, which must be reviewed rather than silenced, and `ci:wiki` includes broader canon checks. The new unit suite tests noindex/redirect/conflict rejection, idempotence, atomic preflight and body preservation against a genuine wiki page. These commands are a **review checklist**, not a claim that they ran on GitHub during this PR.

- Real HTTP: test production apex/www redirects, HTTP→HTTPS, `/about` vs `/about.html`, category index URL variations and actual rendered response headers.

- Indexed site beyond sitemap: inventory publicly linked games, account pages and other unsitemapped routes to decide deliberate index/noindex/canonical policy without blocking JS-based play.
- Open Graph/content: audit warnings after creating a real Pages artifact and improve genuinely missing article descriptions with approved editorial text; do not stamp generic descriptions or fake `lastmod` dates.
- Historic cross-links: new Graffiti Kings historical archive pages can be linked contextually from the Crypto Moonboys Graffiti Kings chronology after publication and link checks; mass reciprocal links are not recommended.

This is a focused technical fix, **not** a promise of ranking gains or proof that every SEO concern has been eliminated.
