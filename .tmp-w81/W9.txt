6. SELF-EVOLUTION ENGINE — The Meta-Brain (Latest Addition)
This is the layer that makes the entire system self-improving.

How It Works:

Every cycle it runs analyse_performance() — pulls live metrics from all modules.

Compares against 14-day historical baselines.

Triggers early alarms if any metric degrades ≥25% for 3+ cycles (or spikes ≥40%).

Injects strict PRE-RULES into the LLM prompt.

LLM (GPT-4o-mini) decides if upgrade is needed and generates small, safe, isolated code patch.

Patch is saved and logged. (Future workflow can auto-commit.)

Pre-Rules the Agent Must Obey:

Only upgrade if degradation ≥25% for 3+ cycles or big positive spike.

Changes must be tiny (≤80 lines, 1 module).

Never touch core publishing, IPFS, or token logic.

Always backward-compatible.

Output only code or exactly “NO_UPGRADE_NEEDED”.

Ammo Provided to the LLM Every Cycle:

Current vs baseline metrics

Full PRE-RULES

Clear output format

The system now learns when a change is coming and executes upgrades automatically — 100% in-house.
