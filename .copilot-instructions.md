# Copilot Instructions — Crypto Moonboys

## Repository purpose

This is the live website repository for Crypto Moonboys.

Crypto Moonboys is the Graffiti Kings creator umbrella for the Web3 and blockchain world. It is not a game. Games, XP, NFT drops, burn routes, factions, the wiki, Battle Chamber and Block Topia are systems inside the umbrella.

## Canonical positioning

There are two valid onboarding paths:

1. **Moonboy identity path** — users build one or more original 1/1 Moonboy identities through Telegram/faction onboarding, Battle Chamber activity, Arcade XP, eligible free NFT drops, keep/flip/burn and forge progression. Under published terms, the holder owns the licence and royalties assigned to the 1/1. Every 1/1 holder is a HODL Warrior.
2. **Existing identity path** — artists, businesses, product creators, brands and established alter egos keep their identity and use SWARMSY. They do not need a Moonboy, NFT or arcade progression route.

SWARMSY supports both paths with identity, strategy, planning, branding, publishing, growth and momentum.

Moonboys are the new generation of Graffiti Kings identities in the Web3 and blockchain world. GKniftyHEADS is the primary foundation alongside other factions connected to OG Graffiti Kings artists.

## Guardrails

- Required root files (`README.md`, `robots.txt`, `.nojekyll`, `index.html`, `CNAME`) must remain in place.
- All active arcade games remain under `games/`.
- Do not call Crypto Moonboys a game, arcade or NFT project.
- Do not make the Moonboy path mandatory for SWARMSY-only users.
- Do not describe HODL Warriors as passive holders.
- Do not position SWARMSY as separate from the creator umbrella.
- Do not present NFTs as the mission; they are Path 1 artefacts and evolution materials.
- Do not invent legal rights beyond published creator licence and royalty terms.
- Block Topia documentation and code must reflect the verified live survival/mission runtime only.
- Do not reintroduce removed admin shells, dead Block Topia systems or speculative runtime claims.
- `robots.txt` must remain at the repository root.

## Coding conventions

- Scripts in `scripts/` use `.mjs` when they need Node APIs.
- Browser-facing code uses ES modules when already wired that way.
- No new build tools or bundlers.
- Load `/js/api-config.js` before browser code that depends on `MOONBOYS_API.BASE_URL`.
- Preserve reduced-motion and no-JavaScript fallbacks when changing homepage animation copy.
