What SWARMSY Is

SWARMSY is not a generic chatbot. It is a project-manager layer for building living icons: face identities, hidden identities, art-world personas, product worlds, lore systems, campaign signals, proof-safe PR, and community momentum.

SPARKY

The operator inside the HIVE. SPARKY leads the user through intake, memory, proof, campaign handoffs, and next actions.

SWARMSY HIVE

The command centre where the project lives. It holds doctrine, identity state, campaign context, proof, and handoff flows.

Living Icon Engine

The prompt tree for turning a user or hidden identity into lore, visuals, products, PR, and launch momentum.

Action Hub

The user-facing command surface: Start Intake, Load Memory Lock, Campaign Calendar, and Review Proof / Find Proof Gaps.

What It Helps Build

Face Identity

For artists, founders, performers, brands, and creators who want to be the visible centre of the system.

Hidden Identity

For aliases, masked artists, mystery brands, character-led projects, and privacy-first creative worlds.

Campaign Signals

Campaign-day handoffs that use proof, lore, assets, and project state to create public-facing momentum.

Proof-Safe PR

SPARKY checks what claims are safe, what proof is missing, and how to make weak proof look intentional instead of fake.

Current Truth

SWARMSY is being prepared as a hosted web app experience. Normal users should open a URL, log in, and use the HIVE in the browser. They should not need Git, CMD, Yarn, Docker, or developer commands.

The current build already defines the onboarding lane, HIVE creation, doctrine loading, intake handoff, memory lock continuation, campaign calendar handoff, proof review handoff, and MVP release documentation. Some future systems — such as dedicated Memory Lock storage, Proof Tracker database, and advanced optional doctrine loading — remain Phase 2 work.

Rules of the HIVE

  • No fake claims.

  • No fake proof, fake press, fake sales, or fake community.
  • No spam, botnets, or mass unsolicited DMs.
  • Bots are staff, not fake fans.
  • Shock the attention system, not the law.
