Step 1: Link Telegram Before Competitive Play

Why linking matters

The platform needs a persistent identity before it can submit competitive scores, connect faction activity or request server-backed Arcade XP. Unlinked users cannot enter the competitive Arcade.

Step 3: Play and Submit a Run

During the game

Play for score. All active arcade games submit through the shared submitScore() path. The shared path runs after each game ends.

After the game

The platform checks linked authentication and submits the run. The server decides whether it is accepted and whether progression is awarded.

Score does not equal XP

A high score can rank well without awarding the same number of XP. Score and progression are deliberately separate.

How Server Acceptance Works

Signed identity

The run must be connected to valid linked authentication.

Accepted score

The score endpoint must accept the run before it becomes a competitive record.

Progression checks

The server is where dedupe, caps, anti-farm checks, and final Arcade XP awards are decided.

Sync state

If the service is unavailable, a linked run may show a pending state rather than falsely claiming confirmed XP.

Common Problems

My score did not appear.

Confirm Telegram is linked, authentication is current and the score submission returned an accepted state. Unlinked runs are not saved competitively.

My score appeared but my XP did not change.

Score ranking and Arcade XP are separate. The server may reject, cap, deduplicate or delay progression while still handling the score state separately.

I linked Telegram before, but the page asks again.

Refresh the signed link with /gklink in @WIKICOMSBOT, then reload the page.
