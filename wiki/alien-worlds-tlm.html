🪐 Alien Worlds / TLM

✅ Source-cited🎮 Gaming🪙 Cryptocurrencies📅 Last updated: June 2026

Alien Worlds is a blockchain game and metaverse economy built around planets, mining, NFTs, missions, player activity and the token Trilium, usually shown as TLM. For the WAX ecosystem, Alien Worlds is one of the clearest examples of why WAX matters: it shows how a blockchain can support repeated game actions, digital item ownership, marketplace trading and token rewards at consumer scale.[1] [2]

TLM is not the same type of asset as WAXP. WAXP is the native token of the WAX blockchain. TLM is the token associated with the Alien Worlds game economy. The two connect because Alien Worlds uses WAX infrastructure for game and NFT activity, while TLM represents Alien Worlds-specific utility, incentives and metaverse participation.[2] [3]

Overview

Alien Worlds is one of the best-known blockchain-game examples connected to WAX. It is commonly described as a decentralised metaverse in which players use NFTs, mine resources, interact with planets and participate in an economy built around Trilium. Public market profiles identify TLM as the Alien Worlds token and describe the project as spanning gameplay, decentralised finance style mechanics and NFT ownership.[2]

The reason Alien Worlds matters for a WAX wiki is not only its size or name recognition. It matters because it demonstrates a real use case for high-frequency blockchain actions. A game cannot feel playable if every small action is slow, expensive or hard to sign. WAX’s account and resource model is designed to support frequent transactions, and Alien Worlds became one of the clearest examples of a WAX-connected game economy reaching mainstream crypto visibility.

Alien Worlds also shows how blockchain games blur categories. It is not only a game. It is also a token economy, NFT collection system, marketplace activity loop, governance experiment and metaverse brand. That makes it a useful reference point for projects that want to build lore, art, tokens and gameplay into one connected structure.

What TLM is

Trilium, or TLM, is the token associated with Alien Worlds. Market profiles describe it as the utility token of the Alien Worlds metaverse and connect it to gameplay, planet governance and reward mechanics.[2] [3]

In a game economy, a token has to do more than exist. It can be used to coordinate incentives, represent in-game value, support player choices, provide reward flows, and connect on-chain activity to broader markets. TLM sits in that role for Alien Worlds. It is the token identity of the game, while WAX provides a key infrastructure layer for many user actions.

For collectors and players, this distinction is important. Buying TLM is not the same as buying WAXP. Holding Alien Worlds NFTs is not the same as holding TLM. Using WAX for Alien Worlds activity is not the same as investing in WAXP. These are connected layers, but they are not interchangeable.

Why WAX matters

WAX matters to Alien Worlds because WAX is built around high-volume digital commerce and NFT activity. Official WAX documentation highlights WAX as a chain for games, collectibles, tokens, meme coins and NFTs, and specifically names Alien Worlds among WAX-supported game ecosystems.[4]

A game like Alien Worlds needs repeated actions: mining, claiming, moving assets, interacting with NFTs, checking inventory, and participating in game-specific mechanics. These flows would become painful if every action required the user to calculate a high gas fee. WAX’s model is better suited to that pattern because it is designed around resources and account activity rather than only per-transaction gas thinking.[5]

That is the wider WAX lesson. WAX is not just a place to park a token. It is an infrastructure environment for applications that expect repeated user behaviour. Alien Worlds is one of the most visible examples of that use case.

Game loop and economy

The broad Alien Worlds loop is based on player participation in a metaverse economy: users interact with planets, use NFTs, mine or earn Trilium, and participate in systems that connect game actions to token flow. Public profiles describe TLM as tied to planet governance and gameplay incentives, while the project’s own site presents Alien Worlds as a metaverse with missions, mining and player participation.[1] [2]

The key design point is that Alien Worlds makes the token part of a loop rather than a standalone object. Tokens, NFTs and player actions reinforce each other. A player does not only hold a balance; they interact with tools, planets, assets, missions and communities. This is the structure many blockchain-game projects try to build, but it is difficult to sustain because it requires real retention, balanced rewards and ongoing content.

That is why Alien Worlds belongs in a serious WAX section. It gives readers a concrete reference for the difference between a token attached to a webpage and a token inside an active game economy.

NFTs and digital items

Alien Worlds also matters because of its NFT layer. WAX NFT infrastructure supports collections, schemas, templates and structured asset data. For a game, that structure can represent tools, land, characters, equipment, rewards or other game objects. The WAX docs describe NFTs through these structural concepts, which help marketplaces and apps understand what an asset is and how it should behave.[6]

In a normal collectible project, an NFT may be mostly visual. In a game economy, an NFT can also carry function. It can affect gameplay, rarity, progression, reward rate, appearance, access, status or strategy. Alien Worlds helped popularise that idea to a broad WAX audience by tying digital items to repeated gameplay.

Lessons for Crypto Moonboys

Alien Worlds is useful to Crypto Moonboys because it proves that WAX-native projects can be more than static NFT drops. A project can combine lore, user activity, tokens, items, missions, staking-like incentives, marketplace trading and game systems. That matters for any future Crypto Moonboys, GraffPUNKS, NBG or GKniftyHEADS experience that wants to turn collectibles into a living economy.

The lesson is not to copy Alien Worlds directly. The lesson is to understand the layers: WAXP for chain infrastructure, NFTs for digital objects, project tokens for economy design, wallets for user access, marketplaces for liquidity, lore for meaning, and games for repeated participation. Alien Worlds is one of the clearest WAX examples where those layers are visible together.

Risks and caveats

This page is informational and not financial advice. Game tokens are high risk. Their value can depend on player retention, emissions, game balance, market liquidity, exchange support, bot pressure, reward design, regulatory changes and team execution. A token can be attached to a known game and still decline sharply if the economy weakens.

Blockchain-game users should also separate entertainment value from investment assumptions. Playing a game, collecting NFTs and buying a token are three different decisions. The fact that Alien Worlds is important to WAX history does not mean TLM is guaranteed to perform well in the market. The wiki records relevance, not price prediction.
