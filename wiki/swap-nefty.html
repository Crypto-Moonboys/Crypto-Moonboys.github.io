💱 swap.nefty

✅ Live WAX RPC⏱ 24h cache📅 Last updated: August 2026

swap.nefty is the WAX smart contract account used here as a live source for Nefty swap token-pair data. This page reads the WAX chain through public RPC endpoints, discovers the contract ABI, loads the most likely pool/pair table, and displays the two token sides, contracts, token quantities and any value fields exposed by the row data.

The list is cached in the visitor browser for 24 hours. After the cache expires, the page pulls fresh chain data again. This keeps the public website lightweight while still showing current WAX pair data without needing a server-side database.

How it works

The page calls WAX RPC get_info to confirm a live endpoint, calls get_abi for swap.nefty, then chooses the first ABI table that looks like a pool or pair table. It then loads rows through get_table_rows using code: swap.nefty and scope: swap.nefty.

The main display intentionally stays read-only. It does not sign transactions, connect wallets or recommend trades. It only surfaces contract table data in a cleaner wiki format.

Plain English: this is a WAX pair viewer, not a swap button and not financial advice.

Risks

  • RPC endpoints can rate-limit, go stale, or temporarily fail.
  • Contract ABIs and table names can change; the parser is defensive but cannot guarantee every future row shape.
  • Token symbols can be spoofed on WAX. Always check the token contract, not only the symbol.
  • Thin liquidity can make displayed quantities misleading for real trading depth.
