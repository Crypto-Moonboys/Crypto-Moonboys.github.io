Create Your Moonboy

Your character can become far more than a profile picture. Build their history, personality, faction relationships, visual signature, stories, printable art and a personal wiki, one decision at a time. This public guide shows you how to work with ChatGPT; no SWARMSY installation or programming experience is required.

Create with ChatGPT

The linked page prepares a ChatGPT starter message. Press Send inside ChatGPT, or copy the starter if the handoff did not fill the chat input.

Start with what is actually yours

If you hold an actual GKniftyHEADS or Moonboy NFT, begin with its image or a link and the verified collection and asset ID. A template ID identifies a type, not an individual asset. Never treat rarity, ownership, licence, faction, costume or powers as confirmed merely from a character name. A screenshot, description or sample artwork may still be a good creative starting point; mark unverified details clearly.

If you are inventing a new character from nothing, that is valid creative work too. ChatGPT can develop an original proposal, but an invented character is not automatically an issued NFT, a qualifying licensed identity or an approved official entry into the shared universe. Your original character work remains distinct from Crypto Moonboys brand assets and other creators' established characters.

The six-part creation path

1. Confirm the anchor

Character name, image or description, known NFT traits, faction or unknown status and first question. One answer at a time is enough.

2. Develop the personality

Build the character's voice, motivation, fears, contradiction, reputation and human-scale problems before inventing impossible abilities.

3. Connect to the world

Use the accepted 3008 chronology, Block Topia, the Street Kingdoms and the specific faction's customs. Keep new supporting cast and events explicitly marked as creator-proposed lore.

4. Make useful things

Turn the character into an icon, sticker, print, permitted mural concept, comic, zine, music identity, merchandise sample or visual story. These begin as drafts until actually made.

5. Build a personal wiki

Create a simple site with a character page, timeline, faction page, image gallery and sources. ChatGPT can help draft the content and website files where tools are available; hosting and publishing require a real service and user approval.

6. Save and extend

Keep a portable Project Bible showing confirmed facts, user-approved new material, unresolved sources, image credits and the next scene. Optional community canon submission is a separate review process, not an automatic promotion.

What ChatGPT should make first

A useful first session produces an identity card, a short source map, three specific possible directions only if needed, and a draft paragraph or simple piece of art. It should never demand that a beginner complete a huge form first. If the user has an image, use it and ask only for the most important missing fact. If the user has no image, propose an original silhouette and name explicitly as drafts. Build depth over successive sessions.

For an established character, ask for a full biography when ready. The extended template covers origin, faction, strengths and limitations, role in Block Topia, HODL WARS as fiction, relationships, creator meaning, a proper feature story and future website metadata. Keep every confirmed detail separate from an imaginative new addition.

Rights, sources and publishing

Owning or developing an image does not automatically transfer the entire Crypto Moonboys or Graffiti Kings brand, another character, or shared canon. A qualifying NFT may carry specific creator rights only under its current published terms. Never claim a mint, official acceptance, sale, reward or a wall installation occurred without evidence. Use original artwork and owned or explicitly authorised spaces for physical display.

To continue later, save a plain-text character file containing the name, verified traits, approved personal facts, source URLs, unconfirmed claims, made assets and the next task. Paste that file into the next ChatGPT conversation when needed. Public source material must not reveal editorial-only future story outcomes.
