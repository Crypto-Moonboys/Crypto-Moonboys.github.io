🎮 FGL Token

✅ Source-cited🎮 WAX Game Token📅 Last updated: June 2026

FGL Token is a Web3 gaming token presented by FGL as “a token that you can truly use across multiple games.” The project’s public site says FGL functions as currency across FGL’s crypto-games portfolio and currently exists on WAX and Immutable zkEVM, with Cardano stated as coming soon. The site also links directly to WAX trading access through Alcor/Taco-style WAX routes.[1]

WAX role

FGL belongs in the WAX index because the official site names WAX directly and includes WAX-related game/token routes. Outlaw Troopers is described as a WAX play-and-own game using FGL, and the FGL token is described as existing on WAX as part of a multi-chain setup.[1] [2]

Game portfolio

The FGL site references several game experiences and properties, including Outlaw Troopers, Story Charmed, Machiavellic, Mecha World, Crash Cars and Cosmic Clash. The site describes a range of genres: interactive illustrated stories, sci-fi sandbox empire simulation, open sandbox MMO design, mecha progression, car physics and tactical auto-chess style gameplay.[1]

This range matters because a multi-game token needs breadth. If a token is meant to operate across games, each game becomes a potential use case, sink, reward route or audience entry point. The hard part is maintaining coherent token economics across games that may work very differently.

Outlaw Troopers

Outlaw Troopers is presented by FGL as a sci-fi sandbox game combining strategic empire simulation with single-player and multiplayer real-time combat. The site says players send Troopers to seek valuable treasure and currency while growing an empire, and that the game is season-based with resets across empire levels and resources. The page also says Outlaw Troopers originally launched on WAX in 2022 and is expanding to more blockchains.[2]

For WAX game design, Outlaw Troopers is a strong example of season resets, NFT roles, missions, gear, encounters, black-market play, ranking and token rewards being tied together.

Cosmic Clash

The FGL site describes Cosmic Clash as a tactical auto-chess style game where users collect spaceships, arrange a battlegroup and automatically fight another fleet. It says the focus is collecting and trading NFTs, defeating players and advancing to the next galaxy for better ships. The site also references AtomicHub for collecting and trading ship NFTs.[1]

FGL company background

The FGL site says Lucrative Gaming, also known as FGL, was founded in 2007 and has worked with large volumes of web and mobile games. The site states that FGL has worked with over 70,000 developers, put more than 50 games in top-ten app charts, worked with over 100,000 web games and built GamerSafe, described there as a universal in-game microtransaction system for web gaming.[3]

This history is relevant because FGL is not presented as a new anonymous Web3-only token launch. The project positions itself as a gaming company applying long-running web/mobile game experience to Web3 token and NFT economies.

Risks

This page is informational and not financial advice. Multi-game tokens carry risk. Game activity can change, chain support can change, token demand can vary between games, and reward systems can become unsustainable if not balanced. Users should verify live token contracts, exchange routes, game status, NFT utility and official announcements before buying or using FGL.
