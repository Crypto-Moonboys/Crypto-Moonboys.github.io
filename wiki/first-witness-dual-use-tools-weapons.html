Tools, Weapons and Dual-Use Technology

First WitnessTechnology ethics · Section 80Last updated: October 2026

The same tool can repair a wall, breach a wall or map everybody behind it. First Witness ethics therefore looks beyond whether technology is labelled peaceful or dangerous.

Intent is not enough

A tool built for good can be predictably misused. A tool built for defence can become an instrument of domination. Designers are not responsible for every imaginable misuse, but predictable consequences belong in the design conversation.

Capability and access

Some powerful tools become safer when widely distributed; others become more dangerous. “Decentralise it” is therefore not an automatic moral answer.

Auditability

High-impact systems should leave evidence of use where doing so does not create a greater danger. Invisible power is difficult to challenge.

Weapons

Communities differ on weapon ownership, but mainstream war ethics demands clear distinction between defensive custody and status built around the ability to harm.

Surveillance tools

A technology that protects one group by making another permanently observable triggers the Witness/Privacy conflict. Emergency deployment requires an expiry path.

The builder's question

If the person you distrust most controlled this tool tomorrow, what protections would you wish you had designed today?
