## Publication and navigation

metadata, Article JSON-LD with original `isBasedOn` URL, source credit, native
contents and related links. The library uses CollectionPage structured data.
The 94 routes are registered in `approved-pages.json` and generated search,
entity/link graph and sitemap outputs. The capped mobile graph remains a
derived subset of the full graph.

New reading lists are added to ten existing category pages. Search displays
all eighteen category cards in four groups after its input, before the existing
guide links and article list. The oversized Search illustration is hidden and
its heading compacted so the input appears first. No top-nav change is made.

Dashboard coverage comes from `js/blog-editions.json`: 94 sources, 93 editions,
10 categories, one exact duplicate. Existing graph-analysis reports are also
regenerated from the expanded inventory: gaps, expansion/growth plans, cluster
health, authority drift/trust, entity changes, timeline analysis, predictive
growth, governance and publishing readiness. These are analysis/planning
outputs; no executor, external publisher or automated content job is enabled.

A long-query fallback defect exposed by the larger index is corrected:
meaningful subject coverage precedes substring points from short words when
strict matching fails. The existing score formula and ordinary browse ranking
remain unchanged. A CSS regression assertion is scoped to the actual emoji
rule; the previous expression incorrectly consumed all later stylesheet rules.
The original base CSS reproduces the false failure without this batch.
