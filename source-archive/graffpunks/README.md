# GraffPUNKS blog source archive

[w81.zip](w81.zip) preserves all 94 original text files from the uploaded
RAW CANNON collection. It uses the original W81 ZIP packaging recovered from
commit `44f180a6da267c6bc476c6ca6b777dd297ee1e65`. Each original filename and
file SHA-256 matches the upload. Both copies of the High Hats source are kept
as separate entries because their original filenames differ.

- Original ZIP SHA-256 is `eb3f1902b8f5e8b8e20a16c18c925a072bf81699ca404f3abb04c4f5b9a34b96`.
- The [source inventory](../../brand-canon/wiki-rewrites/raw-canon-20261008-source-register.csv) lists the individual hashes.
- The [reading library](../../wiki/graffpunks-reading-library.html) links to the
  cleaned editions. The [edition map](../../js/blog-editions.json) matches each
  original filename with its corresponding page.
- The Pages artifact publishes the reading editions. This source directory
  lives outside the artifact's public directory allowlist.
